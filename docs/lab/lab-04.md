
# CSF302 Coding Lab: Unit 4 — Topics 6 and 7

## Topic 6: Efficient Modular Exponentiation

1. Implement a naive modular exponentiation algorithm to calculate `a^b mod m` using repeated multiplication.

2. Implement binary exponentiation using the square-and-multiply method to calculate `a^b mod m` efficiently.

3. Write a program to compare the outputs of naive and binary modular exponentiation for different bases, exponents, and moduli.

4. Modify your binary exponentiation implementation to use bitwise operations to check whether the exponent is odd and divide it by two.

5. Implement input validation to handle zero exponents, negative exponents, negative bases, and invalid moduli.

6. Write a program to measure and compare the execution times of naive and binary modular exponentiation for increasing exponent values.

## Topic 7: Efficient Matrix Modular Exponentiation

7. Implement a function to multiply two square matrices and reduce each resulting element modulo a given positive integer.

8. Implement a function to generate an identity matrix of a specified dimension.

9. Implement naive matrix exponentiation to calculate `A^n mod m` using repeated matrix multiplication.

10. Implement binary matrix exponentiation using repeated squaring to calculate `A^n mod m` efficiently.

11. Write a program to compare naive and binary matrix exponentiation for different matrices, exponents, and moduli.

12. Implement a function to calculate the nth Fibonacci number modulo `m` using matrix exponentiation.

13. Write a program to calculate large Fibonacci numbers using matrix exponentiation without generating all preceding Fibonacci numbers.

14. Implement matrix exponentiation to count the number of walks of exactly `k` edges between two vertices in a directed graph, using its adjacency matrix and a given modulus.

15. Write a program to benchmark naive and binary matrix exponentiation for different matrix dimensions and exponent values.
